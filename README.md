# Interactive-News-Portal
A web-based news portal developed using PHP and MySQL.
## Project Structure

- /auth → User authentication system
- /admin → Admin dashboard and content management
- /comments → Comment handling system
- /api → Backend APIs
- /inc → Database and reusable functions
- /news → News viewing system

## Key Features
- User login & registration
- Admin dashboard
- News CRUD operations
- Category management
- Comment system
- Trending news
- Report generation
